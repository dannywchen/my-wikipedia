My first submission (that worked): 
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {

        /* alright we are going to implement a big o notation n^2 solution to this problem

        we create three for loops where the first for loop has the i loop iterator which tracks the start of the substring and
        the second for loop with the j loop iterator variable tracks the end of the substring. Then the actual duplicate
        counter will be in the third for loop with the k loop iterator variable. We can basically say that we compare the end
        of substring and compare to all other characters in the String to see if any is a duplicate, and we will restrain it
        so it doesn't compare to itself. 

        when there is a duplicate, we break out of this for loop that sees if there is a duplicate. then the next part is the if else statement where if it is duplicate we can break out of the loop and move on to see more substrings.

        if there is no dupicate, we set current substring length as the value of "j-i+1". then we check if current substring length is larger than the max value, if it is larger than max value than set the max value as current length. 

        */ 

        int maxLength = 0;

        if (s.length() == 0){
            return 0;
        }

        for (int i = 0; i < s.length(); i++){

            
            for (int j = i; j < s.length(); j++){

              boolean isDuplicate = false;
                for (int k = i; k < j; k++ ) {
                    if (s.charAt(k) == s.charAt(j)){
                        isDuplicate = true;
                        break;
                    } 
                }

                if (isDuplicate){
                    break;
                } else {
                    int current_length = j-i+1;
                    if (current_length > maxLength){
                        maxLength = current_length;
                    }
                }
            }
        }
        return maxLength;
    }
}
```
