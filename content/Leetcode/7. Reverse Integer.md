class Solution {

    public int reverse(int x) {
        int reversedValue = 0;
        boolean isNegative = false;
        
        if (x == Integer.MIN_VALUE) {
            return 0;
        }
        
        if (x < 0) {
            isNegative = true;
            x = x * -1;
        }
        
        while (x != 0) {
            int digit = x % 10; // 123 % 10 =
            if (reversedValue > Integer.MAX_VALUE / 10) {
                return 0;
            }
            reversedValue = reversedValue * 10 + digit; // 0 * 10 + 3 = 3
            x = x/10;
        }
        
        if (isNegative){
            reversedValue *= -1;
        }
        return reversedValue;
    }
}

__Extra notes:__
`int` = signed 32 bit two's complement integer
`long` = 64 bit sized integer
Two's complement representation = Allows it to hold both positive and negative values

There is a difference between signed vs unsigned integer, which is that signed will have both positive and negative values (essentially having a tighter range -2,147,483,648 to 2,147,483,647) compared to unsigned which has no negative numbers but double the positive max (0 to 4,294,967,295).
